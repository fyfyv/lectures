# функции и процедуры
## объявление, вызов и передача параметров
Функция - именованный блок кода с одной задачей. Она может принять данные и может вернуть результат. В C++ отдельного слова "процедура" нет. Действие без результата это тоже функция, с типом void.
этот блок в коде прописываться не будет, но он там подразумевается
```C++
#include <iostream>
#include <vector>
#include <string>
using namespace std;
```

Одна функция - одна задача. Если в имени нужны "и ввести, и написать, и напечатать", функцию пора дробить.
 Два вида по результату:

| вид            | тип                | что делает                             |
| -------------- | ------------------ | -------------------------------------- |
| с результатом  | int,bouble,bool... | считает и отдает значение через return |
| без результата | void               | делает дейстие: печать, ввод, запись   |

>[!tip] параметр и аргумент 
>Параметр - имя в объявлении функции, локальная переменная внутри нее
>Аргумент - значение, которое подставляют при вызове

return 0; из main - условный сигнал "программа завершилась штатно". Ненулевое значение обычно означает ошибку. Если у main нет своего return, язык подставляет 0.

## Объявление, определение, вызов

| Запись                        | Что это                                        |
| ----------------------------- | ---------------------------------------------- |
| int max(int a; int b);        | объявление, прототип: имени и типов достаточно |
| int max(int a; int b) { ... } | определение: здесь тело                        |
| max(x,y)                      | вызов                                          |
без прототипа вызов ниже функции не соберется.

## передача параметров в функцию
По умолчанию аргумент передается по значению: функция получает копию. Параметр - локальная переменная. Запись в параметр не меняет переменную в вызывающем коде.

## Возврат значения
Функция с результатом (не void): обязана вернуть значение указанного типа через return. Результат можно присвоить в переменную или подставить прямо в выражение:
```C++
int square(int x) {
    return x * x; // обязателен return с типом int[cite: 111, 124]
}
int a = square(5); // a = 25[cite: 124]
```
Если в функции с типом не void забыть return и попытаться использовать результат, это неопределенное поведение (UB), а не «пустота».

Функция без результата (void): ничего не подставляет в выражение (запись int x = printHello(); не скомпилируется).   
```C++
void printPositive(int x) {
    if (x <= 0) return; // досрочный выход из функции[cite: 125]
    cout << x << endl;
}
```
В void-функции return; без значения законен и служит для досрочного выхода. Запись вида return 5; в void — ошибка компиляции.   

## Области видимости

|                 | локальные                         | глобальные                |
| --------------- | --------------------------------- | ------------------------- |
| где объявлена?  | внутри функции, включая параметры | вне всех функций          |
| кто видит?      | только эта функция                | любая функция этого файла |
| когда исчезнет? | при выходе из функции             | при завершении программы  |

Чужую локальную переменную прочитать или изменить нельзя: вне своей функции она не существует.

Глобальную переменную функция изменить может, но это делает программу хрупкой: данные лучше передавать параметрами и возвращать через return.

## Типичные ошибки
- Нет return у не-void функции: тип обещает вернуть значение, но внутри только печать (cout). 
- Печать — это действие, а не результат.   
- Ожидание значения от void: попытка присвоить результат void-функции в переменную (int x = print();).   
- Иллюзия изменения переменной: ожидание, что изменение аргумента внутри функции изменит переменную в main (передается копия!).   
- Вызов до объявления: вызов функции ниже по коду без вынесенного наверх прототипа.
