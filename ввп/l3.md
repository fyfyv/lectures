# Основные понятия программирования
## Переменные
Переменная — именованная область памяти. У неё есть тип (какие значения допустимы) и значение, которое программа может прочитать и заменить.

Имя нужно программисту. Процессору важно, по какому адресу лежит значение и сколько байт оно занимает.
> Тип задаётся при объявлении и сам по себе не меняется. Меняется значение.

### Как объявить переменную
```C++
int age = 20;
double price = 19.99;
char grade = 'A';        // один символ — одинарные кавычки
bool isStudent = true;
string name = "Алексей"; // текст — двойные кавычки
```
> Точка с запятой заканчивает инструкцию.

### Правила имён
- Имя начинается с буквы или _.
- Дальше можно буквы, цифры и _.
- Регистр различается: age и Age — разные переменные.
- Пробелы и знаки вроде - или ! в имени нельзя.
- Имя не может совпадать со словом языка: int, if, return.
- Имя не может начинаться с цифры.
- Имена, которые начинаются с _ и заглавной буквы или с __ зарезервированы языком. В учебном коде их лучше не брать.

> Локальная переменная без инициализации содержит неопределённое значение. Читать его до присваивания нельзя: по стандарту это неопределённое поведение. На практике часто виден «мусор», но программа может сломаться и иначе.

Глобальные переменные и static язык обнуляет сам. На локальные это правило не распространяется.

> Сразу пишите начальное значение: int age = 0;

## Типы данных
### Встроенные типы, которые нужны сегодня
|   Тип |   Что хранит          |   Пример      |   Размер          |
|-------|-----------------------|---------------|-------------------|
|int    |целые числа	        |-5, 0, 100     |   обычно 4 байта  |
|double |дробные числа          |3.14, -0.001   |	обычно 8 байт   |

sizeof(char) всегда равен 1. Размеры int, double и bool стандарт жёстко не фиксирует; в таблице обычные значения на ПК. Есть ещё float (обычно 4 байта); для учёбы хватает double.

> string — не встроенный тип

>string (std::string) — тип из стандартной библиотеки для текста произвольной длины. Подключается заголовком ```<string>```.

|Запись     |Тип    |Смысл                                      |
|-----------|-------|-------------------------------------------|
|'A'	    |char	|один символ                                |
|"A"        |строка	|текст из одного символа и завершающего нуля|

## Операторы
Четыре группы на сегодня
|Группа         |Операторы              |Зачем                  |
|---------------|-----------------------|-----------------------|
|Арифметика     |+, -, *, /, %, ++, --  |посчитать              |
|Сравнение      |==, !=, >, <, <=, >=   |получить bool          |
|Логика         |&&, ||, !              |собрать условие        |
|Присваивание   |=, +=, -=, *=          |записать в переменную  |

> % — остаток от деления. && читается «и», || — «или», ! — «не». Побитовые операторы и ?: сегодня не разбираем.   

Целые делятся с отбрасыванием дроби   
```C++
int a = 10 + 5;                     // 15
bool isEqual = (a == 15);           // true
bool inside = (a > 10) && (a < 20); // true
a += 3;                             // то же, что a = a + 3; теперь 18
cout << (7 / 2) << endl;            // 3
cout << (7 % 2) << endl;            // 1
cout << (7.0 / 2) << endl;          // 3.5
```
Оба операнда int — результат / тоже int. Один double — результат дробный.   

### Инкремент и декремент
++ прибавляет 1, -- вычитает 1.   
```C++
int n = 5;
int a = n++; // сначала отдали старое значение: a = 5, затем n = 6
int b = ++n; // сначала увеличили: n = 7, затем b = 7
```
> Запись после имени (n++) возвращает старое значение. Запись до имени (++n) — уже новое.
---
= и == — разные операторы
```C++
if (x = 5) { }  // записали 5 в x; условие истинно, потому что 5 != 0
if (x = 0) { }  // записали 0; условие ложно
if (x == 5) { } // сравнили, x не меняется
```
> = присваивает и возвращает записанное значение. == сравнивает и возвращает true или false, переменную слева не меняет.   Присваивание внутри if почти всегда опечатка. Компилятор часто предупреждает, но программу всё равно собирает.

## Условия
Программа выбирает, какую ветку выполнить
### if, else if, else
```C++
if (условие) {
    // условие истинно
} else if (другое_условие) {
    // первое ложно, это истинно
} else {
    // все проверки выше ложны
}
```
- Проверки идут сверху вниз. Срабатывает первая истинная ветка, остальные пропускаются.
- Фигурные скобки ставьте даже для одной строки. Так сложнее потерять тело ветки.

Пример: оценка по баллам
```C++
int score = 85;
if (score >= 90) {
    cout << "Отлично!";
} else if (score >= 70) {
    cout << "Хорошо";
} else {
    cout << "Нужно подтянуться";
}
```

## Циклы
Один и тот же блок выполняется, пока условие истинно

### Три цикла
- for — число повторений известно заранее.   
    - for (инициализация; условие; шаг) { }   
- while — сначала проверка, потом тело. Тело может не выполниться ни разу.   
    - while (условие) { }   
- do-while — сначала тело, потом проверка. Тело выполнится хотя бы один раз.   
    - do { } while (условие);

> for - Порядок на каждом круге: проверить условие, выполнить тело, выполнить шаг i++

> while может не зайти в тело ни разу. do-while заходит всегда хотя бы один раз.
```C++
int count = 3;
while (count > 0) {
    cout << "Осталось: " << count-- << endl;
}
```
> count-- сначала отдаёт текущее число в cout, затем уменьшает count.

## Типичные ошибки
### Синтаксис
1) Нет ; в конце инструкции.   Компилятор пишет что-то вроде expected ';' before.   
2) В условии написали = вместо ==.   if (x = 5) записывает 5 и считается истинным.   
3) Не закрыта скобка (), {} или [].   Сообщение часто указывает уже на конец файла: expected '}' at end of input.

Читайте первую ошибку компилятора. Следующие часто следствие той же скобки.   

### Данные и циклы
4. Чтение переменной до присваивания.   int x; cout << x; — неопределённое поведение, а не «законный мусор».
5. Цикл не заканчивается: забыли менять переменную условия.   
```C++
int i = 0;
while (i < 10) {
    cout << i << endl; // нет i++, условие вечно истинно
}
```
Опечатка в имени: coutt, retunr, sting.   Компилятор ответит was not declared in this scope.
