# Интерпретаторы и компиляторы
компиляторы и интерпретаторы - специальные программы, которые переводят наш код в то, что процессор может выполнить.

Машинный код это последовательность нулей и единиц, которую напрямую выполняет процессор.

Языки программирования (C++, Python) — не исполняются напрямую.

Языки высокого уровня (C++, Python) должны быть преобразованы в машинный код!

Нужен переводчик: компилятор или интерпретатор.

# Компилятор vs Интерпретатор
| Компилятор                                         | Интерпретатор                                                 |
| -------------------------------------------------- | ------------------------------------------------------------- |
| Переводит ВЕСЬ код до запуска                      | Переводит и выполняет КОД ПО СТРОКАМ                          |
| Создаёт исполняемый файл (.exe)                    | Не создаёт отдельного файла                                   |
| Быстрое выполнение                                 | Медленнее (перевод на лету)                                   |
| Ошибки находятся ДО запуска                        | Ошибки проявляются во время выполнения                        |
| Исходный код → КОМПИЛЯТОР → Программа.exe → ЗАПУСК | Исходный код → ИНТЕРПРЕТАТОР → Выполнение (строка за строкой) |

- Компилированные программы быстрее, потому что всё готово заранее

Компилятор: весь код → машинный код до запуска.

Интерпретатор: код выполняется по строчкам.

Примеры: C++ — компилируется, Python — интерпретируется.

# Как работает компилятор?
Этапы компиляции:
1. Лексический анализ   → Разбивка кода на лексемы (слова, знаки)
2. Синтаксический анализ   → Проверка грамматики, построение дерева
3. Семантический анализ   → Проверка смысла (типы, объявления)
4. Генерация машинного кода   → Создание исполняемого файла
Исходный код → Лексер → Парсер → Семантика → Генератор кода → .exe

## Этап 1. Лексический анализ
Лексический анализ (лексер)
• Разбивает исходный код на лексемы (tokens).
• Удаляет пробелы, комментарии.
Пример:  int x = 5 + 3;  → [int] [x] [=] [5] [+] [3] [;]

## 2. Синтаксический анализ (парсинг)
• Проверяет, правильно ли упорядочены лексемы.
• Строит синтаксическое дерево — внутреннее представление структуры кода.
• Обнаруживает синтаксические ошибки:   
    if ```(```x == 5 ```{```    → пропущена скобка    
    int y = ;                   → неполная инструкция

## Этап 3. Семантический анализ
• Проверяет смысл кода.
• Ошибки не в синтаксисе, а в логике и типах.
• Примеры проверок:    
- Использование необъявленной переменной    
- Несоответствие типов: int x = "hello";    
- Выход за границы массива (на этом этапе или позже)
Используется таблица символов.

## Этап 4. Генерация машинного кода
• Преобразует промежуточное представление программы в исполняемый машинный код.

• Результат:
- Исполняемый файл (.exe, .out)
- Байт-код (в некоторых системах)
- Ассемблерный код

• Может включать оптимизацию:
- Ускорение выполнения
- Снижение потребления памяти

[Синтаксическое дерево] → [Генератор кода] → [Оптимизация] → [Машинный код]

Генерация кода — создание исполняемого файла.

Результат: .exe, байт-код, ассемблер.

Оптимизация улучшает скорость и размер программы.
