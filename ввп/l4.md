алгоритм - клнечная последовательность однозначных шагов, от исходных данных к результату.

Структура данных - способ хранить набор значений так, чтобы нужные шаги были удобными

массив - неизменяемая структура, набор элементов одного типа. Размер задается при создании и не меняется. элементы лежат в памяти подряд. Номер элемента называется индексом и начинается с 0.

Индекс за пределами массива - неопределенное поведение. Программа не обязана сообщить об ошибке. Для int arr[100] допустимы только индексы от 0 до 99.

## vector
vector шаблонный класс, проще говоря массив у которого можно менять число элементов.

std::vector - динамический массив из стандартной библиотеки. Элементы по-прежнему лежат подряд, индекс с нуля. Число элементов меняется во время работы программы.

если создать вектор командой
```C++
vector<int> v;
vector<int> v(100);
```
то вектор создается пустым.
вторая команда сразу создаст вектор размером сто.

```C++
int arr[100];
int arr[100] = {};
```
выдаст неопределенное поведение
вторая команда создаст 100 нулей


### операции над векторами
push_back(x) - дописать элемент в конец
size() - сколько элементов сейчас
v[i] элемент с индексом i, с нуля, v[i] за границей - снова неопределенное поведение.
Метод v.at(i) в этом случае бросает исключение. Пока пользуемся индексом только если он точно меньше size().

## стек (last in, first out)
### принцип LIFO
стек (stack) - структура с доступом только к одному концу, веришне.
LIFO (last in, first out) - последним сложил, первым забрал.

### операции стека C++
push(x) - положить x на вершину
top() - посмотреть вершину, не снимая
pop() - снять вершину
empty() - пуст ли стек

пример кода:
```C++
#include <stack>
stack<inr> s;
s.push(10);
s.push(20);
cout << s.top() << endl; // 20
s.pop(); // снимает 20 и ничего не возвращает
```

## очередь (first in, first out)
### прицип FIFO
Очередь (queue) -  добавление в один конец, удаление с другого.
FIFO (first in, first out) -  кто встал раньше, того обслужат раньше.

### операции в очереди C++
push(x) - встать в конец
front() - посмотреть начало, не удаляя
pop() - убрать элемент из начала
empty() - пуста ли очередь

push всегда пишет в конец. pop всегда забирает из начала. Середину по индексу очередь не показывает.

пример кода:
```C++
#include <queue>
queue<int> q;
q.push(10);
q.push(20);
cout << q.front() << endl; // 10
q.pop() // уходит 10, не 20
```

## Связный список
Связный список — цепочка элементов, разбросанных в разных местах памяти[cite: 89]. Каждый элемент хранит значение и ссылку (указатель) на следующий[cite: 89].

- Быстрого доступа по индексу нет: чтобы дойти до i-го элемента, нужно пройти по всем ссылкам с начала[cite: 89].
- Удобен, когда нужно часто вставлять или удалять элементы в середину, не сдвигая весь хвост[cite: 89].
- Подробнее разбирается в лекции по указателям[cite: 55, 89].

## Алгоритм на стеке: проверка правильности скобок
Задача: проверить, что каждой открывающей скобке соответствует закрывающая того же типа и вложенность не нарушена (например, `([ ])` — верно, а `([ )]` — ошибка)[cite: 91, 95].

### Шаги алгоритма:
1. Создать пустой стек символов[cite: 92].
2. Идти по строке слева направо[cite: 92].
3. Если символ открывающий `(`, `[`, `{` — делаем `push`[cite: 92].
4. Если закрывающий:
   - Стек пуст — ошибка (лишняя закрывающая)[cite: 92].
   - На вершине стека (`top()`) лежит не пара к текущей скобке — ошибка (порядок нарушен)[cite: 92].
   - Пара совпала — снимаем скобку со стека через `pop()`[cite: 92].
5. Если в конце строки стек пуст — всё расставлено верно[cite: 92]. Если что-то осталось — не хватает закрывающих скобок[cite: 91, 92].

## Итоги и типичные ошибки
1. **Выход за границы массива или вектора:** `arr[100]` при 100 элементах — UB (индексы строго 0..99)[cite: 63, 65, 68].
2. **Пустой вектор:** у чистого `vector<int> v;` размер 0, обращение `v[0]` до первого `push_back` вызовет ошибку / UB[cite: 70].
3. **Ошибки со стеком и очередью:**
   - Попытка прочитать или снять элемент из пустой структуры[cite: 76, 96].
   - `pop()` удаляет элемент, но **не возвращает его значение**[cite: 76, 82]. Чтобы прочитать, сначала вызываем `top()` (у стека) или `front()` (у очереди)[cite: 76, 82].
