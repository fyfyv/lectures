## про решение глобальных задач
Алгоритм решения глобальных задач:
	определить тз и уточнить детали
	определиться с реализацией
Глобальная задача
	наборы задач
	подзадачи
	набор действий
	данные
блок схемма - графическое представление какого-либо алгоритма
	блок схема дает только базовое понятие какого-либо алгоритма и не подходит для сложных задач
псевдокод - код, удобный для восприятия, но не понятный для машины
	(чаще всего его юзают только студенты первокурсники)
остальные инсрументы:
	uml - unified modeling language
	idef - i-cam definition или integrated definition
	aris - architecture of integrated information system
	rup - rational unified process

Для наглядного изображения процессов и явлений используют схемы, но под одним и тем же символом люди могут иметь ввиду разное. Чтобы исключить разночтения был придуман UML.

**API (Application Programming Interface)** — это набор правил и готовых команд, с помощью которых разные программы могут общаться друг с другом
